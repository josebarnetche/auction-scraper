Features

Automated daily scraping, market price comparison, and static dashboard generation via GitHub Actions.

Multi-Source Scraping

Scrapes 8 auction sources including CSJN, SCBA, COMPR.AR, and private auctioneers like Adrian Mercado and Banco Ciudad.

Compares against MercadoLibre market prices using blue dollar rates for accurate ARS/USD conversion and valuation.
