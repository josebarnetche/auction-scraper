Preguntas Frecuentes

Quien puede ser afiliado?

Cualquiera con una wallet de Ethereum/Base. No hay requisitos minimos.

Como se calculan las comisiones?

10% de cada pago API (creditos, suscripciones, pagos por request).

Cuanto dura la atribucion?

30 dias desde el click. Si el usuario paga dentro de ese periodo, ganas la comision.

Hay limite de referidos?

No hay limite. Pero cada wallet solo cuenta como un referido (anti-fraude).
